# Unidad 3 - Factory Method

Repositorio de ejercicios del patrón **Factory Method**, resueltos en Java. Cada ejercicio es independiente y contiene el código fuente, instrucciones y una captura de su ejecución.

## Estructura

```text
3.E.1/
  Ejercicio-1/
    src/                  Código Java del ejercicio
    captura/ejecucion.png Captura de la ejecución
    README.md             Descripción y pasos para ejecutar
  ...
3.E.2/
  Ejercicio-1/
  ...
README.md                  Guía general del repositorio
```

## Requisitos

- JDK 17 o posterior.
- No se requieren dependencias externas.

Entra a la carpeta del ejercicio que quieras consultar y sigue sus instrucciones en el `README.md` correspondiente. Los ejemplos se compilan y ejecutan de manera independiente.

Los conectores de base de datos, almacenamiento en nube y dispositivos IoT son simulaciones locales. ZIP, TAR y GZIP producen datos comprimidos en memoria. Los importadores XML/JSON y exportadores PDF son ejemplos didácticos simplificados, no implementaciones completas de esos estándares. Las firmas fiscales y notariales ilustran validación y criptografía, pero no producen documentos oficiales ni sustituyen requisitos legales.
